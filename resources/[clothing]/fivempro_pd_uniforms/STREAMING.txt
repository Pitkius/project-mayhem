PD UNIFORMA — „Oversized assets“ (97 perspejimai)
================================================

KAS VYKSTA
--------
FiveM krauna VISUS failus is stream/ paleidus resursa. Kiekvienas .ytd
issipakuoja i RAM (daznai 32–64 MB VIENAM failui), nors diske failas ~7–22 MB.

Tai NE script klaida — addon teksturos yra per didelio rezoliucijos
(dazniausiai 2048x2048 be DXT suspaudimo).

SVARBU: visos 5 kolekcijos NAUDOJAMOS (config_duty_outfits.lua):
  mp_f_pdmot, mp_f_pdv2, mp_f_pdvyrai, mp_m_pdv2, mp_m_pdvyrai
Negalima tiesiog istrinti stream/ aplanku — uniformos nebeveiks.

REZULTATAS jei neoptimizuosi
----------------------------
- MLO / masinos / kiti addon gali neuzsikrauti
- Zaidimas lagina prisijungus
- Konsoleje 97+ geltoni perspejimai (normalu su siuo pack)

SPRENDIMAS A — OpenIV (rekomenduojama, palieki PD apranga)
---------------------------------------------------------
1. Atsisiusti OpenIV: https://openiv.com/
2. Edit mode → Enable for FiveM
3. Eik i: resources/[clothing]/fivempro_pd_uniforms/stream/
4. Kiekvienam dideliam .ytd (ypac jbib_*, task_*, accs_*):
   a) Atidaryk .ytd → Export visas teksturas → PNG
   b) Sumažink PNG iki 512x512 arba 1024x1024 (Photoshop / GIMP)
   c) Import atgal → formatas DXT5 (ne raw PNG viduje!)
   d) Issaugok .ytd
5. Ypac svarbu sutvarkyti:
   - mp_m_freemode_01_mp_m_pdv2^task_004_u.ydd (128 MB RAM!)
   - visus *jbib_diff_*_uni.ytd (64 MB RAM)
6. Perkrauk serveri → perspejimai turetu sumazeti iki 0 ar keliu.

Didziausi failai (PowerShell):
  powershell -File tools/list_large_clothing_assets.ps1

SPRENDIMAS B — Laikinai isjungti (greitas testas)
-------------------------------------------------
cfg/20_qb.cfg — uzkomentuok:
  # ensure fivempro_pd_uniforms
  # ensure fivempro_gmp_uniforms
PD naudos vanilla drabuzius, streaming problemos dings.

SPRENDIMAS C — Naujas lengvesnis pack
-------------------------------------
Jei turi originalu moda su mazesne rezoliucija — pakeisk stream/ turini
arba pirk/naudok pack su 512px teksturinomis.
