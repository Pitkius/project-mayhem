fivempro_interrogation – 2 variantai
====================================

KUR TESTUOTI (žemėlapio blipai)
-------------------------------
Visi testai — LS oro uostas (ta pati eilė kaip fivempro_drugs):

  • „Test: gaujų tardymas“ (oranžinis) — gaujų įrangos NPC
  • „Test: policijos tardymas“ (mėlynas) — policijos apklausa be durų
  • Šalia: „Test: LS oro uostas“ (fivempro_drugs) — narkotikai / ginklai

Koordinatės: ~-887, -3208, 14 (GPS /tp -887 -3208 14)

MRPD (production policija):
  • Blipas „MRPD apklausos kambarys“ — ~475, -1003, 26
  • Reikia police job + on duty
  • Durys: ls_mrpd_interview (fivempro_ltpd)

Blipus išjungti: Config.ShowBlips = false

TEST PARDUOTUVĖ (gaujos)
------------------------
Config.EnableTestShop = true
LS oro uostas — blipas „Test: gaujų tardymas“
Kaina: Config.TestShop.price (default 250€ cash)
Production: EnableTestShop = false

VARIANTAS A – GAUJOS (itemas)
-----------------------------
Item: gang_interrog_kit (qb-core/shared/items.lua)
- Nusipirk NPC arba /giveitem [id] gang_interrog_kit 1
- Naudok itemą → [E] padėti ant žemės, scroll sukti
- Išsaugoma DB (fivempro_interrogation_kits) – lieka po server restart
- Surinkti: tas kas padėjo ARBA admin (target ant dėžės)
- Target: Pradėti RP spaudimą → sutikimas → mygtukai: Dantys / Benzinas / Elektra / Baigti

VARIANTAS B – POLICIJA (fiksuotos vietos)
-----------------------------------------
Config.PoliceStations — LS oro uostas (test) + MRPD (production).
Tik police + on duty (qb-target).
- Įtariamasis: paprasta sėdėjimo animacija prie stalo
- Pareigūnas: mygtukai – Pradėti apklausą (misijos anim), Prožektorius, Trenkti, Baigti → MDT

restart fivempro_ltpd
